# Veil — Environmental Intelligence

A cinematic single-page discovery experience for finding unusual places through atmosphere, rarity, sensory character, and emotional resonance.

## Live site

https://stefan-saran.github.io/Veil-Environmental-Intelligence/

## Build

The project is dependency-light: a single responsive `index.html` with semantic HTML, CSS design tokens, native motion, reduced-motion support, and front-end discovery interactions.
